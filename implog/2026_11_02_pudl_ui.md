# pudl ui: the graph explorer, embedded and live

`pudl ui` serves the web graph explorer from the pudl binary against the
workspace catalog, and opens a browser. Design: [docs/frontend.md](../docs/frontend.md#live-pudl-ui).

## Decisions

- **No Wails.** Wails still builds its frontend with npm, and its webview needs
  CGo, which would break pudl's `CGO_ENABLED=0` builds and releases. Instead a
  stdlib `net/http` server serves a bundle embedded with `go:embed`.
- **Committed bundle, no Node to build pudl.** `make web` (Vite) writes
  `internal/webui/static`, which is committed. `make check-web` rebuilds it
  and fails on a diff; the build is reproducible. The directory is not
  `dist`: the user's global gitignore ignores `dist/` and would have dropped
  the bundle silently.
- **Read-only and loopback by default.** It listens on `127.0.0.1:7468`. A
  non-loopback `--addr` needs `--allow-remote`. A Host-header guard returns
  403 to any other host, which blocks DNS rebinding.
- **Live means read on each request.** `/api/graph` opens the catalog and
  loads rules per request (the same code as `pudl graph export`), so new
  observations and rules need no restart. Schema changes do, because the
  schema inferrer is cached per process.
- **The origin comes from the source.** The UI labels data LIVE only when it
  fetched it from the server that served the page. A document's own `origin`
  field is ignored.

## Public API

- `internal/webui`: `Assets() fs.FS`.
- `internal/uiserver`: `Handler(Options) http.Handler`,
  `Options{Assets, Graph GraphFunc, Workspace, Version, AllowedHosts}`,
  `Serve(ctx, net.Listener, http.Handler)`, `IsLoopback`.
- `cmd/ui.go`: `pudl ui [--addr] [--no-open] [--allow-remote]`.
  `cmd/graph.go`: `buildWorkspaceGraph(ctx)` shared with `graph export`.
- Web: `LiveGraphSource`, `servedByPudl()`; source order is `?graph=` then
  `?demo` then live (if pudl served the page) then demo.
  `parseCanonicalGraph(data, label, origin)`. A Reload button keeps view
  state. `PUDL_API` makes the Vite dev server proxy `/api`.
- Make: `web`, `check-web`.

## Verification

- `internal/uiserver` tests: live graph and no-store, JSON errors, health,
  SPA fallback and immutable assets, foreign-host rejection, explicit allow
  list, graceful shutdown. `internal/webui` checks that index.html references
  only embedded bundles. `cmd` tests: non-loopback refused without
  `--allow-remote`, malformed addr. The JSON contract, help golden and CLI
  reference are updated.
- Manual: a `CGO_ENABLED=0` binary (40 MB) served the fixture workspace.
  `/api/health` and `/api/graph` (86 resources, 63 relationships, origin
  live) answer, a foreign Host gets 403, and in Chromium the LIVE banner shows
  and Reload keeps a collapsed group collapsed.

## Follow-up: auto-refresh (pudl-3s1)

- `database.CatalogDB.ChangeStamp()`: one query over the fact write sequence
  (`fact_sequence.next`), the entry count, max rowid and max updated_at, and
  the snapshot count and latest time.
- `uiserver.FileTreeStamp(dirs...)`: fingerprints .cue files by path, size
  and mtime. `Options.Stamp`, `GET /api/version`, and a mutex-guarded graph
  cache keyed by stamp. `graphexport.Meta.Version`.
- `cmd/ui.go` `uiGraphSource`: the stamp covers the catalog, the rule dirs
  and the schema dirs. A schema change resets `inference` and `validator`
  caches before the next build.
- Web: `GraphSource.version()`, `useAutoRefresh` (3 s, paused while hidden or
  reloading), and an "auto" toggle in the banner. Synthetic owner groups show
  the owner type's code (PROJ, ACCT).
- Verified in Chromium: with `pudl ui` on an AWS-only workspace, running GCP
  fixture collectors in the workspace made the GCP project, network, subnets
  and firewalls appear within one poll, and a collapsed VPC stayed collapsed.
