# Go 1.26.10 for GO-2026-6809

Addresses `pudl-pps`. The pre-merge gate for the `sre-focus` branch ran
`make vulncheck` (govulncheck v1.8.0). It reported GO-2026-6809 in
`crypto/x509@go1.26.9`, fixed in go1.26.10 and reachable from pudl code. The
advisory postdates the 2026-10-10 remediation (`pudl-ew9`). The branch did not
introduce it: `go.mod` was unchanged, and `main` had the same exposure.

## Changes

Raised the Go requirement and toolchain pins from 1.26.9 to 1.26.10:

- `go.mod`
- `mise.toml`
- `.github/workflows/go.yml` (`GO_VERSION`)
- the GitLab pipeline image that `internal/init/init.go` generates
- the active docs: README, getting-started, TESTING, architecture

Historical records (implogs and earlier `docs/plan.md` entries) keep the
versions in use at the time. No dependency versions changed.

Line delta: production Go +1/−1 (the generated image tag). No test changes.
