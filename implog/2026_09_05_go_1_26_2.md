# Go 1.26.2 toolchain

## Changes

- Raised the module's minimum Go version to 1.26.2.
- Added a project-local `mise.toml` pin so development uses Go 1.26.2 regardless
  of the user's global mise version.
- Unified all Go CI jobs on 1.26.2, including the real-mu smoke job.
- Updated installation, architecture, and testing documentation and the GitLab
  pipeline example generated during initialization.

## Public API

No CLI or Go API changes. Building PUDL now requires Go 1.26.2 or newer.

## Validation

Confirmed `mise exec -- go version` reports `go1.26.2 darwin/arm64` and GOROOT
points to the matching mise installation. Passed with that toolchain:

- `go test ./...`
- `go test -race -gcflags=all=-d=checkptr=0 ./...` (existing CDC exception)
- `go vet ./...`
- `go build ./...`
- `go run ./internal/skills/gen -check`
- `make test-git-walkthrough`
- `make test-kick-tires`, using published mu v0.3.5
- `git diff --check`

No dependency upgrades or application compatibility fixes were required.
